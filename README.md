# 👑 VOGUE BOYS — Luxury Fashion Maison for Young Gentlemen

A state-of-the-art, high-converting E-Commerce web application dedicated exclusively to boys' fashion and attire (Ages 2 to 16). Built with semantic HTML5, modern CSS3 (with dynamic Light/Dark luxury themes), and responsive vanilla JavaScript.

---

## 🌟 Key Features

### 1. Curated Boys' Fashion Catalog
- **Festive & Ethnic Collection**: Royal embroidered raw-silk Sherwanis, Brocade Nehru jacket sets, and comfort-lined Kurta Pajamas.
- **Bespoke Tuxedos & Formals**: Midnight navy 3-piece satin shawl lapel suits, preppy Oxford shirt sets with suspenders and velvet bowties.
- **Urban Streetwear**: Vintage varsity boiled-wool bomber jackets, heavyweight hoodies, and fleece-lined denim trucker jackets.
- **Summer Linen & Resort**: French flax linen mandarin collar shirts and flexible Supima chinos.
- **Winter Outerwear**: Sub-zero hooded down quilted puffer jackets with detachable fleece trims.

### 2. High-Converting E-Commerce Functionality
- **Live Search & Autocomplete**: Instant search with keyboard shortcut (`/`) and real-time product dropdown with images and price previews.
- **Advanced Dynamic Filters**:
  - Filter by Category (*Festive*, *Formal*, *Streetwear*, *Linen Casual*, *Winter*).
  - Filter by Age Group (*Toddler 2-4Y*, *Kids 5-8Y*, *Junior 9-12Y*, *Teen 13-16Y*).
  - Color Swatches (*Navy*, *Maroon*, *Ivory*, *Sage*, *Emerald*, *Denim*).
  - Multi-Criteria Sorting (*Featured*, *Price: Low to High*, *Price: High to Low*, *Customer Rating*, *Newest Drops*).
- **Interactive Quick View Modal**: High-res gallery preview, size selectors, fabric & hypoallergenic lining details, and quantity stepper.
- **Slide-Out Interactive Cart Drawer**:
  - Dynamic **Free Express Shipping Progress Bar** (unlocks above $99).
  - Real-time quantity adjustments and item removals.
  - Active Promo Code Engine with instant discounts (`GENT20` for 20% off, `FIRST10` for 10% off, `VIP25` for 25% off).
- **Multi-Step Checkout Flow**:
  - **Step 1**: Shipping details & courier speed selection (Express Courier vs Rush Overnight).
  - **Step 2**: Interactive credit card preview with real-time card number, cardholder name, and expiry date simulation.
  - **Step 3**: Order receipt & confirmation card with unique tracking ID (`#VB-2026-XXXX`), itemized list, and printable invoice.
- **Saved Wishlist Flyout**: Save favorites with one-click "Move to Bag" and `localStorage` persistence.
- **Boy's Fit & Size Master Guide**: Interactive calculator based on age (2-16Y) and build (Slim, Regular, Husky) with height, chest, and trouser measurements, featuring 1.5-inch hidden expansion seam allowances.
- **Multi-Currency Converter**: Real-time pricing toggle between **USD ($)**, **EUR (€)**, **GBP (£)**, and **INR (₹)**.
- **Dark / Light Luxury Mode**: Sleek midnight contrast theme with instant toggle.

## 🚀 Running the Storefront

The local server is already running! You can access it anytime at:
```bash
http://localhost:3000
```

To run manually or restart the server:
```bash
node server.js
```
Or simply open [index.html](file:///c:/github/index.html) directly in any web browser.
